------------ INTERPRETION AND COMPILATION OF JS-------------------------------------------------------------
JS is interpreted language. runs code line by line unlike compiled language which compiles the code all at once. 
modern JS engine uses both mix of compilation and interpretation known as "JUST IN TIME" COMPILATION. Source code gets compiled into machine code and executed jjust after compilation ends.  
	
-------How JIT works for javascript--------------------------
	1. Parsing - Code is first syntax parsed into data structure - AST - abstract syntax tree - where its split into pieces that are meaningful to the language and are stored into a tree in a structured manner. code is broken down into tokens. this also checks if there are any syntax errors. THE RESULTING TREE WILL GENERATE THE MACHINE CODE. 
	
	2. compilation - JS Engine takes the AST and compiles it into machine code. JIT (just in time compilation) - it uses both interpreter alongwith a compiler. 
		Interpreter - executes code line by line. this is faster. 
		compilation - code is compiled before execution. code is compiled into optimized version and it is executed. THIS IS MORE EFFICIENT. 
		JS can be interpreted or compiled based on JS engine. 
		in some JS engines, there is something called as AOT - AHEAD OF TIME COMPILATION. 
	3. Execution - memory heap - function and variables are stored and call stack is there to execute the AST. its in sync with garbage collection too. 

Depending upon where JS is running, they are additional different env specific features in the JRE. for e.g, IN browser - DOM events.

---------------------------------------CLOSURE------------------------------------
CLOSURES - function along with its lexical scope is known as closure. Closure is a combination of function bundled together with reference to its surrounding state. when inner function is returned, they still maintain their lexical scope irrespective of when its used outside as a reference to outer variable. FUNCTION ALONGWITH ITS LEXICAL SCOPE STATES IS RETURNED... THAT IS CLOSURE.  

	-- Closures gives a function access to its outer scope. In JS, closures are created everytime a new function is called.  

    function createCounter() {
      let count = 0;
      return function() {
        count++;
        return count;
      };
    }
    const counter1 = createCounter();
    console.log(counter1()); // Output: 1
    console.log(counter1()); // Output: 2
    const counter2 = createCounter();
    console.log(counter2()); // Output: 1	
	
	- CLosure is used to make private variables.
	- It is used to preserve states between function calls. for a single function, if assigned a different variable for same function call, it will maintain seperate state for that function call. 
	- Implement currying & memoization. 
	
	WHY WE RETURN THE FUNCTION - BY RETURNING THE FUNCTION, WE ARE ACTUALLY packaging the inner function alongwith its surrounding. this allows inner function to remember and access the surrounding state even after outer function has finished executing.

---------------------------MEMORY LEAKS IN JAVASCRIPT---------------------------------------------------------
Memory leaks happens when application holds onto the objects in memory that are no longer needed preventing the garbage collector to reclaim it and make it free.

---Garbage collector in JS------
3 steps it does.

Throttling - throttling will prevent a function from running if it has run “recently”. Throttling also ensures a function is run regularly at a fixed rate.
Throttling is used to call a function after every millisecond or a particular interval of time only the first click is executed immediately.
 
const throttle = (func, limit) => {
  let inThrottle;
  return function() {
    const args = arguments;
    const context = this;
    if (!inThrottle) {
      func.apply(context, args);
      inThrottle = true;
      setTimeout(() => inThrottle = false, limit);  // after each call throttle is set to false.. avoiding the call for sometime. 
    }
  }
}

--------------------------------------for keeping track of last call------------------------
const throttle = (func, limit) => {
  let lastFunc;
  let lastRan;
  return function() {
    const context = this;
    const args = arguments;
    if (!lastRan) {
      func.apply(context, args)
      lastRan = Date.now();			// first time will set the last ran time
    } else {
      clearTimeout(lastFunc);
      lastFunc = setTimeout(function() {
          if ((Date.now() - lastRan) >= limit) {    /// if time now - last ran is greater than the limit set, then call
            func.apply(context, args);
            lastRan = Date.now();
          }
       }, limit - (Date.now() - lastRan));
    }
  }
}
